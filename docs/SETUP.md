# Setup

Installation, datasets, and pretrained-model retrieval.

## Requirements

- Python 3.10 or newer
- ~2 GB of disk for dependencies (PyTorch dominates)
- For training only: ~10 GB extra for raw datasets + processed sequences
- Optional GPU is **not required**: the entire pipeline (training and
  inference) runs on CPU. Training a single LOSO fold on URFD takes
  ~3 minutes on a modern desktop CPU.

## Install

```bash
git clone https://github.com/egi03/ai-fall-detection-system.git
cd ai-fall-detection-system

python -m venv venv
# Windows
venv\Scripts\activate
# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt
```

Dependencies (see [`requirements.txt`](../requirements.txt)):

| Package | Role |
|---|---|
| `torch` | LSTM / ST-GCN training and inference |
| `mediapipe` | Default 33-landmark pose backend |
| `ultralytics` | YOLOv8 person detector + YOLO-Pose alternative backend |
| `rtmlib` | RTMPose alternative pose backend (ONNX, 17 COCO) |
| `opencv-python-headless` | Frame I/O, drawing primitives |
| `onnx` / `onnxruntime` | Optional ONNX export path |
| `pyyaml`, `pandas`, `scikit-learn` | Config, dataframes, metrics |
| `fastapi`, `uvicorn`, `jinja2` | Optional web demo (uploader) |
| `pytest` | Test suite |

## Pretrained models

```bash
python scripts/download_models.py
```

Downloads ~33 MB of weights to `models/`:

- `models/urfd/` — Run 3 LOSO BiLSTM (5 fold checkpoints)
- `models/run5_stride2_aug/` — Run 5 LOSO BiLSTM (5 fold checkpoints), the best single model
- Optional cross-dataset checkpoints (`models/cross_*`) downloaded on demand

The MediaPipe pose model (`pose_landmarker_full.task`, ~6 MB) is also fetched here.

## Datasets (training and evaluation only)

The demo does not need any dataset — only the model weights above.
The instructions here are for re-training from scratch or running
the full evaluation pipeline.

### URFD — primary training dataset

- 5 subjects, 70 fall sequences + 40 ADL sequences
- Side-by-side depth + RGB MP4s; the loader auto-crops the RGB right half
- Download: <http://fenix.ur.edu.pl/~mkepski/ds/uf.html>
- Place under `data/data/raw/urfd/`

### Le2i — cross-dataset evaluation

- 6 rooms (Coffee Room ×2, Home ×2, Lecture, Office)
- 140+ sequences with annotated fall frames
- Download: see the Le2i dataset page (academic mirror)
- Place under `data/data/raw/le2i/`

### UP-Fall — additional cross-dataset evaluation

- 17 subjects, 11 activities (5 fall types, 6 ADLs), 2 camera angles
- This project uses the **Zenodo 3D skeleton dataset** (DOI 10.5281/zenodo.12773013),
  which provides pre-extracted 33-joint keypoints
- Bulk-download script: `scripts/download_upfall.py`

> **Why double-nested `data/data/`?** The original archive extracts a
> `data/` directory inside the repo `data/` directory. The config and
> all loaders work with this layout — do not flatten it without also
> updating `config/config.yaml`.

## Preprocessing

Run after datasets are in place:

```bash
python scripts/preprocess.py --dataset urfd
python scripts/preprocess.py --dataset le2i
```

Each script extracts MediaPipe keypoints per frame, builds windowed
sequences according to `features.window_size` and `features.window_stride`,
and writes them under `data/data/processed/<dataset>/`.

Subject-independent splits are generated by `src/data_processing/splitter.py`
and saved to `data/data/splits/`. The same `seed: 42` is used everywhere.

## Sanity check

```bash
python -m pytest -q
```

Expected output: `261 passed`. If anything fails on a fresh install,
double-check the Python version and that `models/pose_landmarker_full.task`
was downloaded.
